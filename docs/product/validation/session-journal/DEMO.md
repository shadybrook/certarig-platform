# Fifteen-minute presentation and five-minute demo

Planned timing, not an attended rehearsal: title 0:30; problem 1:00; objectives 1:00; existing system 0:45; architecture 1:15; tools 0:45; live demo 5:00; results 2:00; limitations 1:45; conclusion 1:00.

## Five-minute live sequence

1. 0:00–0:50: select the thermal bench/session. Inspect the immutable definition, permitted observation tools, shared limits and available source records.
2. 0:50–1:30: show stale-data or incompatible-unit refusal, or an unfamiliar electrical description's analysis-only report. Explain the required correction and re-evaluation.
3. 1:30–2:10: inspect the corrected evaluation and raw traces. In the design prototype, explicitly identify deterministic fixtures. In the platform, qualification must use the actual qualified broker before a real receipt is claimed.
4. 2:10–3:00: independent Reviewer inspects the exact version/team and approves observation. Start separately. A role dropdown is only a prototype affordance; it does not demonstrate genuine two-account login.
5. 3:00–4:00: inspect observation health, lease and evidence. Show raw measurements and imported-recording provenance separately from explanations.
6. 4:00–5:00: revoke from another destination. Export and verify actual evidence if prerequisites passed. Otherwise show the explicit isolation refusal and distinguish fixture JSON from independently verified production bundles.

Do not operate physical hardware, create paid model calls or hide unrun qualification during a rehearsal. Complete the genuine login, container and relevant device gates before claiming them in a university demonstration. Record the actual demo link only after recording it.
