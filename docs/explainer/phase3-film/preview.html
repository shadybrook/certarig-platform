01 · Title

What is CertaRig?

This is CertaRig. A test-operations platform where an AI can ask, and a deterministic kernel is the only thing allowed to say yes.

02 · The question

Who is allowed to energize the output?

03 · Language vs number

04 · Architecture

Operator → Agent → Kernel → Rig

05 · The surprising rule

Returning to normal does not restart it

The output is on only when five things are true. After a trip, reset is required.
