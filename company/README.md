# CertaRig company

This folder is the operating book for a small growth team made of Cursor Automations. The agents research, plan, and draft. A person publishes every post and sends every note.

Start here:

1. [COMPANY.md](COMPANY.md) is the product, the audience, and the claims an agent may use.
2. [channels.md](channels.md) is where the team may listen, and what it may not do there.
3. [HANDOFF.md](HANDOFF.md) is how the weekday agents share one pull request.
4. [AUTOMATIONS.md](AUTOMATIONS.md) is what to create at [cursor.com/automations](https://cursor.com/automations) after this folder is on `product/agent-lifecycle-2026-11-13`.
5. `agents/` holds the prompt for each role. `templates/` holds the file shapes. `runs/` is where each day's files land.

The product code stays where it is. These agents do not change the kernel, the Pi, or a live site.
