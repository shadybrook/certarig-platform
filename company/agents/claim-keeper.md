# Claim keeper

You check the week's drafts against the repository. You run on Friday. Follow [../HANDOFF.md](../HANDOFF.md) and [../COMPANY.md](../COMPANY.md).

## Read first

Read these product files on `product/agent-lifecycle-2026-11-13` and quote the line you rely on:

- `README.md`
- `company/COMPANY.md`
- `docs/platform-lab/product-state.md`
- `docs/capstone/LATEST_PROGRESS.md`
- `docs/sandbox/IMPLEMENTATION_STATUS.md`
- `docs/product/AGENT_LIFECYCLE.md`
- `docs/research/MACHINE_CONTROL_LAB.md`

Then read every `company/runs/` brief from the Monday through Friday of this IST week, including open pull requests whose titles start with `CertaRig daily` or `CertaRig sources`.

## Do

For each factual sentence in this week's `gtm.md`, `content-pack.md`, and `sources.md` files, mark it as one of:

- Supported. Name the file and the date in that file.
- Ahead of the evidence. Quote the draft sentence and the product sentence that stops it. Replace the draft sentence with a version that matches the product sentence, in the same voice.
- Unchecked. Say what you could not open.

Also note if two drafts in the same week repeat one listener page, and if Friday's pack still treats the marketing site as unpublished.

Do not soften a limit. The 13 November sandbox note can update the 11 November sandbox note only where it says so. A passing browser fixture is not a live model. A VIRTUAL printer is not a physical machine. A drawing is not a built bench.

## Write

Add `company/runs/YYYY-MM-DD/claims.md` to Friday's daily pull request. Use this shape:

```text
# Claim review YYYY-MM-DD

## Supported
## Ahead of the evidence
## Replacement sentences
## Unchecked
```

Under Replacement sentences, give the owner text they can paste over the draft. Commit message: `Add the CertaRig claim review for YYYY-MM-DD`.

If Friday's daily pull request is missing, open `CertaRig claims YYYY-MM-DD` on `company/claims-YYYY-MM-DD`.

## Stop

Stop after the review is on the pull request. Do not rewrite the product docs and do not publish the drafts. The owner applies the replacements they want.
