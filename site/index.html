The agent may ask.
Only the kernel may say yes.

CertaRig is an evidence-first commissioning and test-operations layer for a mapped rig. People speak English. Rigs speak numbers. 4.2 bar is not a vibe. 15 L/min is not “about that high.”

An agent may choose an approved procedure. A deterministic kernel owns measurements, interlocks, outputs, and the evidence zip. The model never evaluates a measurement.

See the only yes What actually ran

The useful question is not whether a model can operate a bench. It is who is allowed to say yes when a physical output may be energized.

The split of jobs

Language interprets.
Numbers decide.

Putting a language model in the middle and letting it decide whether a relay may energize is the wrong product. Speech is interpretation. Energising an output is a conjunction the model cannot edit. That split is the company. The rest is execution.

The current loop

Observe. Twin. Arm.
Then — and only then — actuate. Restore.

Observation and data quality come before output authority. A hardware procedure does not start unless the same procedure hash already passed on the twin. Restoration of the previous system is part of the proof, not an afterthought. The 24-hour window and the Pi-only gate in today’s code are tactics. The order is not.

01

Observe

Read and record. Sit beside LabVIEW if that is the bench you inherit. Do not command the output until an engineer flips policy. The first 12 Sep ADC run failed because the sweep was incomplete and a channel went invalid. That failure was kept. Quality people buy systems that refuse.

02

Twin

The same procedure hash must pass in simulation before it is allowed on hardware. You do not improvise a hardware procedure that never crossed the twin. A guessed map never auto-energizes. A successful fieldbus browse is not permission to write.

03

Arm

The capability manifest is a fence, not a suggestion. bypass_interlock and override_limits do not exist as callable tools. Policy is never. Humans own irreversible acts: reset_trip and shutdown need a person. ack_operator_step is never an agent tool.

04

Actuate

The kernel is the only thing that may energize an output. Two kernels must not both own the same pin. The agent reaches the rig only through the Edge API, filtered by that manifest. Commanded GPIO is not relay-contact latency — Wave 1 has no contact feedback. We say so.

05

Restore

Gate 5 on the sidecar bench was not a victory lap. The previous system was returned, actuation held disabled, the Pi halted. If you cannot leave the bench as you found it, the run is not finished — and the zip must still say so.

ProcessGuardrail.drive_high

Five terms. One output.
The model does not get a vote.

Break any term and the output is false. After a trip, returning the plant to normal does not restart it. Releasing the emergency stop does not restore a previous permit. Recovery is healthy observation, then an explicit reset, then a new permit. 

output = actuation enabled
      AND permit requested
      AND trip not latched
      AND emergency stop closed
      AND process healthy

The product is the bundle

If a stranger cannot rehash the zip, the run did not happen.

Every consequential run writes procedure, kernel events, checks, and a checksummed bundle. Agent text is labelled narrative. Numbers come from the kernel. An auditor key is read-only. The buyer is the name on the evidence pack — not the person who likes demos.

Honesty about the exporter: pulled zips today record hashes and reports; they do not yet contain the raw physical CSV. That is a known defect. An auditor who cannot replay the waveform will not renew. We would rather say it here than dress a log file up as a pack.

Who writes the cheque

The name on the evidence pack.

Walk away from anyone who wants the kernel removed. That demand is not a pricing objection. University film and the founder’s Pi are not customers.

  • Lab engineer

  • Validation / DV

  • Quality / RA
