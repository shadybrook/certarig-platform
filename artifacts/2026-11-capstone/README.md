## Status of archived reports

Earlier report/deck/hardware-review files are dated review drafts. Their old
candidate parts and price ceilings are superseded by CR-EXT-R1. Neither sourcing
requirements nor model passes establish physical commissioning or release custom
fabrication. No purchases, provider evaluation or new physical acceptance are
claimed here. The standalone electrical drawing is intended for professor review;
the order list need not be attached to the progress email.

Original README files, patches and receipts may mention local paths and prior
publication status. Their contents are preserved as historical records; use the
latest progress page for the present publication status. Generated caches and
operating-system metadata are excluded. Email drafts are local correspondence,
not project deliverables, and are not published.
