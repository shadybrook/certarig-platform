# CertaRig customer-agent proof

Engineering bench owners author, test, review and supervise observation agents. One local organization has distinct Author and Reviewer identities, with grants on two simulator benches. The bench is a reference accessory; the software lifecycle is the product.

The primary job is to move an exact agent version through evaluation and independent review, then observe and revoke it. Agent instructions never grant equipment authority. Fixture checks, trusted Sandbox verification and live-provider qualification must read as distinct states.

Preserve Studio's existing dark engineering workbench, typography, color tokens, native form controls and evidence-oriented language. Use a compact asset/version list alongside an editor and an observation monitor. Reserve red for revocation/refusal and blue for the next permitted action. Support keyboard operation and a stacked mobile layout. No decorative animation, new brand or dashboard metric cards.
